# customer-spending-analysis
Beginner Python project analyzing customer spending behavior
Overview

This project analyzes customer data using Python to identify purchasing behavior and customer segments.

Features
Identify customers who can afford a product
Identify high-value customers
Identify customers who may need discounts
Technologies Used
Python
How to Run
Download the repository
Run analysis.py in Python
Example Output

Customers who can afford the item:
['Alice', 'Carol']

High value customers:
['Alice']

Customers needing discount:
['Bob', 'Dave']
